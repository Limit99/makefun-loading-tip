# Future You Regrets It

A tiny Node/TypeScript program for the make.fun bounty "Loading Screen Gold: A Tip in 200 Characters". It writes one loading-screen tip to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters.

Entry line:

> Tip: while this loads, the code you wrote is being reviewed by a future you who already regrets it.

Run it with: `node main.ts`
